# Book plug-in format

Drop a `.json` file in this folder. Restart Streamlit. The book appears on the Books tab.

You can also upload a JSON in the app or paste raw text without a file.

Reference style is free. `PS 1.1`, `Thomas 3`, `NHC II,2` all work as long as `ref` matches what you type.

Do not paste a living translator's copyrighted Nag Hammadi English as if it were yours. Mead 1921 is public domain. Oxyrhynchus 1897/1904 is public domain.
